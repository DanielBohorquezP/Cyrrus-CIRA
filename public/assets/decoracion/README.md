# decoracion

Fotografía e imágenes decorativas propias de Cyrrus (hero, fondos de sección, retratos del equipo/CEO, etc.).

Convenciones:
- Formato recomendado: WebP o JPG optimizado (idealmente < 300KB por imagen a resolución web).
- Nombrar de forma descriptiva, ej. `hero-oficina.webp`, `ceo-retrato.webp`, `equipo-2026.webp`.
- Hasta que se carguen fotos propias, el sitio usa imágenes de stock de Unsplash como placeholder.
