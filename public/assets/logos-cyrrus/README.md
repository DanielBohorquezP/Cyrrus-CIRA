# logos-cyrrus

Logos propios de Cyrrus Consulting Services.

Coloca aquí las variantes del logo:
- `cyrrus-logo-color.svg` — versión a color, para fondos claros.
- `cyrrus-logo-blanco.svg` — versión en blanco, para fondos oscuros/fotos (usada en el Hero).
- `cyrrus-monograma.svg` — solo el ícono/monograma, para favicon o espacios reducidos.

Formato recomendado: SVG (vectorial, escala sin pérdida). Si solo hay PNG, usar fondo transparente y al menos 512px de ancho.
