# logos-clientes

Logos de las empresas con las que Cyrrus ha trabajado (sección "Experiencia" / prueba social).

Convenciones:
- Nombrar cada archivo con el nombre de la empresa en minúsculas y guiones, ej. `acme-corp.svg`.
- Preferir versión monocromática o a color sobre fondo transparente.
- Formato recomendado: SVG o PNG con fondo transparente.
